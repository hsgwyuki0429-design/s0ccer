# s0ccer

友達と遊ぶための、トップダウン 2D のオンライン対戦サッカー。最大 3v3。
スマホ主軸・PC 対応・クロスプレイあり。

## 現在の状態

**Phase 1（ローカル1人プロトタイプ）まで完了。** オンライン対戦はまだ動かない。

いまの目的はネットワークではなく **手触りの確定**。物理と操作感が固まる前に
オンライン化しても意味がないので、まず1人で蹴って詰められる状態を作ってある。

| Phase | 内容 | 状態 |
|---|---|---|
| 1 | ローカル1人プロトタイプ（物理・操作・描画・ゴール判定） | 完了 |
| 2 | サーバー権威 + オンライン同期（予測 / リコンシリエーション / 補間） | 未着手 |
| 3 | 部屋・パーティ・マッチメイキング | 未着手 |
| 4 | AI（人間と同一の入力しか出せない制約つき） | 未着手 |
| 5 | 試合形式（時間制／先取点制）、リスタート、スコア、UI | 未着手 |

## 動かす

```bash
npm install
npm run dev
```

表示された URL をブラウザで開く。`--host` が有効なので、**同一 LAN のスマホからも
実機で確認できる**（ターミナルに出る Network の URL を開く）。

```bash
npm test       # シミュレーションのテスト
npm run check  # 型チェック
npm run build  # 本番ビルド
```

## 操作

**スマホ**
- 画面左半分: 浮動アナログスティックで移動（指を置いた場所が原点）
- 画面右半分: 長押しでチャージ → **離す瞬間の指の方向**へキック

**PC**
- WASD / 矢印キー: 移動
- マウス長押し: チャージ → **カーソル方向**へキック
- R: リセット

オートエイム・オートパス・シュートのブレは**一切入れていない**。同じチャージ量で
同じ方向へ蹴れば、必ず同じ球が飛ぶ。

## 設計

- [docs/design.md](docs/design.md) — ゲームデザイン（ルール、人数、操作、マッチメイキング）
- [docs/netcode.md](docs/netcode.md) — ネットコード設計（Phase 2 以降の方針）

特筆すべき点として、**GK を置かない代わりにゴール前へ侵入禁止の半円ゾーンを設けている**。
無人のゴールを至近距離から撃つだけの試合になるのを防ぐための、空間によるルール。

## 構成

```
packages/
├─ shared/   決定論シミュレーション（サーバーとクライアントが共有する唯一の物理）
└─ client/   Vite + Canvas のクライアント
```

`shared` はビルド成果物ではなく **ソースを直接** 参照している。Phase 2 でサーバーが
同じコードを読み込むため、両者の物理が分岐しないようにする構成。
